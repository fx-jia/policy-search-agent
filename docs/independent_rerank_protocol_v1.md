# Dense 固定候选的独立局部重排协议

2026-09-22，在首次调用和评分前冻结。研究问题：在当前Dense候选、上下文预算和边界补全不变时，独立gte-rerank-v2排序能否改善完整证据覆盖？允许无收益及退步，不在这轮扫参。

## 范围与对照

- 复用51道开发题的Dense前64候选及1000文档 / 3205块快照，不重新召回、不调用Embedding。99道测试题只核对哈希。
- 对照 `dense` 保持原排序；处理组 `dense_partial_rerank` 只重排原始前32个位置中符合出站要求的片段。后32个位置保持不变，仍可用于边界补全。
- 前32中的受限位置也保持原样，只把模型评过分的片段按分数降序填回参与重排的原位置；同分按原Dense名次。两组都保留同一份64候选、同一份本地正文和Token计数。不得按答案或正例挑选参与片段。
- 这是**有隐私门槛的局部重排对照**，不能称作全部64候选的全量Rerank。出站表示会移除联系信息和链接、对长片段取前1800字符；本地上下文正文不变。无法单独分解模型与这套固定输入表示的作用。
- 模型分数直接排序，不混入BM25或Dense分数；只比较同一次请求内的分数。原生RAGFlow Hybrid及其Rerank流程含其他评分差异，不是本轮单变量对照。

## 隐私与调用

模型沿用当时本地已配置的gte-rerank-v2。其现有SDK默认服务为https://dashscope.aliyuncs.com/api/v1，本轮用同一提供方的text-rerank端点；凭据只在容器内存中读取，不写日志。

重新运行须由部署者设置`POLICY_APPROVED_RERANK_MODEL_ID`，为32位小写十六进制模型行标识，无内置默认值；任务配置中的`model_id`必须与其一致。批准值与任务输入独立传入worker，真实值由未跟踪的本地配置提供。原实验的模型数据库行标识不作为公开默认值。

出站采用与答案无关的规则：来源须标记公开、具有可读文件标题，排除招聘、名单公示、表彰、送达、个案劳动关系、建议答复等类别；或其Chunk已在此前52块审核清单中按原文哈希核验。来源79870无条件禁止。未满足这些规则的UUID标题文档不自动判作安全。

对允许文本移除含联系人、联系地址、邮箱、手机、身份证号码的行，移除网络与图片链接，屏蔽固定电话号码；取前1800字符，正文不足40字符不发出。只发送问题和处理后的片段，不发送标准答案、金标来源、数据库凭据、文档ID或本地路径。保存逐块处理前后哈希和规则依据，不把敏感原文写入报告。该规则和定向复核不等于穷尽全库隐私审核。

预计每题1次、最多51个问题；每题最多32片段，每次问题不超过200字符、片段不超过1800字符、问题重复计入后总字符不超过18000。服务方文档限制gte-rerank-v2每条4000 Token、每次30000 Token；本地字符门槛保守约束输入，但不是精确服务方Token计数，超限响应须保留并停止配置错误。不得为拼接多个请求而直接比较跨请求分数。

第一题作为同一批实验的连通性检查，不额外增加测试题。对暂时网络/服务错误最多重试1次、全批最多60次实际请求；每次尝试均保留，重试不抹去失败记录。鉴权、额度、配置错误立即停止；两道连续问题最终失败也停止。未运行题标为not_run。主表以全部51题为分母，失败无上下文计零；同时给出同一成功子集的诊断，不用成功子集替换主表。没有生成调用或答案正确率评测。

## 指标与复现

两组分别使用原先冻结的ranked和boundary规则；预算2560 cl100k参考Token、boundary前三种子不变。主比较为同一boundary规则下的原始参考证据完整覆盖，ranked作次比较；复用已审核替代证据指标、片段覆盖、文档Recall@5 / MRR@10、上下文Token和已知相关性分桶。报告全部新增/退步，6个政策组bootstrap（seed=20260922，2000次）仅供探索。

配置、代码、出站规则和输入哈希先冻结；出站请求逐条固定后才加载密钥；排序和上下文选择先保存，再加载金标评分。保留提供方返回索引、分数、请求ID、每次尝试耗时和用量。复现评分只读保存响应，不重复付费请求。调用失败的用量若未知，不能按0报告账单。

本轮Dense控制结果应与上轮ranked 44/51、boundary 48/51及选中Chunk逐条一致，否则先排查评测变化。测试集尚未运行；不把开发结果推广为Dense或Rerank普遍优劣。
