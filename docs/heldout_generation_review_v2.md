# 99题生成评分v2：审核反馈落地与一致性重评

2026-09-22。本轮12题定向复核的反馈均已处理，按修订标准对原有198条输出统一重评。没有修改检索、上下文或生成模型，没有重新生成、调用Embedding或付费Judge。**分数变化属于评分纠正，不是算法提升。**

9题有明确用户判断；med-046、074、134是用户提出疑问后，由助手给出解释或二次判读，记录中没有将它们冒充用户确认通过。此次复核也不等于99题及227个复合要点全部经过独立人工验收。

## 为什么不只改12题

用户在med-059明确认可“正文给出了正确内容，年份尚不确定不应清零内容分”。因此检查了全部有效输出的证据不足标记及原拒答理由，将该原则一致应用到两组，而非只修改某一方案的单个样本。

具体涉及med-035、049、059、074、101、118。数值或必要条件仍缺失时只给已答出的点；存在70%/80%冲突却未区分版本时，不给对应点分。主回答完全不提供数值、只有claims提供时，仍不能用claims替代主回答。其他未经确认的必答范围没有自动放宽。

在198条评分记录中，14条的实际指标发生变化；所有变更、前后值及理由见完整差异（本地归档：`experiments/results/private/heldout-generation-test99-review-v2/score_changes.json`，未收入本备份）。原始回答、v1规则、v1评分与冻结文件均保留。

## 如何解释比较结果

Dense减Hybrid的内容完整率差为−1.01个百分点；按29个政策组进行2000次bootstrap，探索性95%区间为[−9.80，+7.07]个百分点。内容完整且有据的差为+2.02个百分点，区间为[−7.53，+11.11]个百分点。两者都不足以支持稳定优劣判断，区间也不包含语义判分误差与后验修改评分口径的影响。

v2的内容计分允许明确保留年份疑问。因此“内容完整且有据”也不自动意味着已明确确认了题问政策版本：Dense的059、074、101，以及Hybrid的059、101，内容计分通过但模型仍标记证据不足。若进一步要求模型未报告证据不足，完整有据题数为Dense 57、Hybrid 55；这是额外诊断，模型标记本身不是人工验证的适用性结论。

两组同时改变了检索与上下文选择，生成差异不能单独归因于边界补全；Hybrid使用原生检索、统一实验生成客户端，不能称为整个RAGFlow网页聊天流程的端到端基线。
