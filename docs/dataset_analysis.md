# 医保数据集分析：第一阶段

本报告分析本地数据快照，不提供现实医保待遇判断。所有计数来自全量脚本扫描；政策标签和来源网址未在线复核。

## 文件、规模与可用性

- 原始文件：`data/documents.jiangsu_and_2city.jsonl`；字段说明：`data/元数据字段说明.md`。
- 大小：32,549,027 字节；SHA-256：`dd052ee5ac20640dcef637eba37624be07fcd2a97f80d2080645ba66d383427c`。
- 可解析记录：3,081；空行：0；无效 JSON 行：0。
- 正文总字符数：3,858,903；最短 / 中位数 / 最长：4 / 752 / 20668。字符不等于 Token。
- 25 个顶层字段；每条有非空政策正文和唯一系统 ID；原始 URL 均非空且无重复。
- 这是政策主文、通知、公示、答复、服务指南和政策问答混合的文档语料，不是只有 QA 对。
- 未发现独立 question/reference_answer/qrels 或 train/dev/test 划分。40 条被原始类型标注为政策问答；它们仍是文档，不是已审核的评测题。
- 本地 data/ 只有 JSONL 和字段说明；3,081 个上游 Markdown 路径均不能在本机按原样解析为现有文件。没有发现与其对应的一套原始 PDF。不能据此评价 OCR 或 PDF 版面解析。

结论：适合构建有地区和明确时间范围的政策证据检索 Benchmark，再扩展为有引用的问答评测。首版应从主文完整的待遇保障/医保经办类通知选题；不是药品目录完整性测试，也不是患者个体报销决策系统。

## 数据质量问题

1. **正文不足**：174 篇不足 100 字。8 组完全相同正文多出 83 条记录；逐组检查长度均不足 100 字，不能把这些占位/残缺文本当作完整政策。短文本只标记，不直接认定无效。
2. **标题异常**：1345 个标题匹配 32～36 位十六进制/连字符样式。影响标题检索和引用展示；后续需从原始出处核对标题。
3. **同名文件**：61 组标题重复，多出 99 条；其中 27 组具有多个非空发布日期。可能为不同年份通知、转载或同名事项，不能只按标题去重，也不能直接推定版本继承关系。
4. **时间与版本**：发文日期范围 1998-12-14～2026-08-03；310 条缺发文日期，871 条缺生效日期。全部版本号为 1、全部标注“是最新版本”，同时含已失效和征求意见文档，这些字段语义不能混用。
   生效日期早于发文日期有 36 条；可能是追溯适用，不能自动判错。2 条废止日期位于扫描日期之后，也不能据此现在排除。
5. **地区混杂**：采集批次仅江苏省/苏州/徐州，但适用区域还含国家级、其他、未知、无锡、南京和外省标签。必须保留原始值；不能用来源批次覆盖适用区域。
6. **话题树并非金标**：24,971 条非空知识点中，只有 10,683 条是正文精确子串；去掉空白后为 16,759 条（67.1%）。不对齐可能来自改写、抽取差错或附件，不能无条件把知识点当原文证据。
7. **编码检查的边界**：UTF-8 解码和 JSON 解析通过，未发现 U+FFFD 替换字符；仍存在正文缺词，如文档 80743 的句子缺少起始时间。无替换字符不代表语义完整或没有乱码。
8. **来源与权利**：网址分布主要是官方医保局/政务网站，另有 1 条公众号网址；这里只保存原始来源，没有确认链接仍可访问、内容是否更新或数据集再发布许可。281 条没有公开发布标签。

- 843 份文档带附件；共 2,617 个顶层附件条目。

## 隐私排查

规则扫描完整记录（含话题树及附件）命中：疑似手机号 36 条；姓名/证件/病历等上下文 613 条。18 位身份证样式本轮未命中。
这些是待审核候选，可能含公开联系人、空白申请表和办事材料要求；既不能把所有命中认作患者隐私，也不能把未命中认作已脱敏。原始完整记录中的姓名等不可能仅靠这组正则彻底识别。
原始数据、候选题证据与逐题结果保留在本地忽略目录；统计文件只保存计数和文档 ID。已有 learning/model-check 的文档也含联系信息，已纳入本地忽略。未上传语料，未调用外部模型，未提交仓库。

## 真实存在的业务检索挑战

- 数字与术语：597 篇含数值百分比，440 篇命中起付/限额/报销等词，235 篇命中药品目录/双通道等词。这些只是文本规则计数，不是完整业务标签。
- 条件组合：徐州新生儿参保与异地备案、苏州家庭成员投保资格、江苏转移接续与生育津贴均有可定位正文。
- 时间差异：徐州文档 79273 与 79320 分别描述不同年度缴费标准；可构造有明确年份的对照问题。没有现成相同 question_id 的多版本答案标签，不能声称已有版本问答集。
- 地区差异：省级最低标准与地市分类标准不能相互替代；跨地区、跨年份问题要明确比较对象，避免把地区效应和时间效应混为一谈。
- 结构问题：正文多已平文化，只有 1 篇命中本轮表格标记规则；不能据此推定仅有 1 篇包含表格信息。很多列表和表格可能已丢失结构。

## 推荐 Benchmark 与入库方案

首版已建立 30 条候选问题，源自 10 份主文通知：28 条单文档问题、2 条双文档比较题；全部有正文字符偏移和 SHA-256，全部仍待人工审核。参考答案为原文证据段，不是被测系统输出。

首版题型覆盖数字、条件、流程、日期、多段信息、同地区跨年对照及跨地区跨年对照。暂不构造药品附表题、无依据的不可答题或未标定条件的地区差异题。不可答题需要明确冻结的知识库和人工排除证据，之后单独增加。

正式版扩充到 100～200 题前，先审核这些候选题，并补充对照方法返回结果池中的其他相关文档。当前标签是已知正例，不是穷尽相关性，不能当成最终测试集分数。按来源文档/同名年度系列/近重复政策组划分 dev 与 test；烟雾测试题固定归开发用途，不再当盲测题。

知识库保留原始主文，不导入生成的 benchmark 问题与参考答案；话题树不与主文重复拼接。全库的原始政策问答文档暂作为自然语料保留，后续检查与评测题的近重复，避免简单抄原始 FAQ 后再检索同一问答。

先从经过审核的 30～50 篇完整政策及相似干扰文档建立独立实验知识库，保留完整来源 ID 映射；冻结模型、分块、语料清单后再运行 Hybrid。原有单篇连通性知识库保持原样。

## 如果将来只有 QA 对而没有原始政策

应把目标收缩为 FAQ 检索或历史问答辅助，不能宣称政策原文引用与现实有效性验证。不能把评测 QA 的答案导入知识库后用同一个 QA 测试。优先补齐独立政策来源；无法补齐时按问题语义簇/来源组拆分、排除近重复，把有无独立证据明确标记。仅改写同一题不构成防泄漏措施，也不能凭常识补 Ground Truth。
