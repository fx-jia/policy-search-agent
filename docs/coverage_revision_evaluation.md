# 固定上下文的子问覆盖复查：首轮开发诊断

2026-09-22。**子问复查在这次运行中补回1题漏答，普通复查没有补回；只支持继续开发验证，暂不替换默认方案。** 评分由助手逐题核对，不是独立人工验收。

## 具体改了什么

保留现有Dense64、boundary2560、短编号引用及qwen3.7-flash。第一轮生成一份初稿；第二轮同时收到原问题、原证据和初稿，从题干识别待答事项，逐项检查答案正文是否回答、是否有证据。遗漏且有依据则补答，缺依据则明确无法确认，最后输出一份统一答案及引用。

这是**生成阶段的子问覆盖检查与修订**。本轮尚未执行子问检索、query改写或独立子答案合并。与此前单轮parts格式实验不同，本次增加一轮复查，并设置同样两次调用的普通复查对照，用于区分针对性检查和额外调用的收益。

每题的两个复查分支共享同一份初稿、相同证据及顺序，互不读取对方结果。9题正常完成，首题med-001初稿遇到TLS EOF，按协议不重试并跳过两个依赖分支。三种条件均保留原定10题分母，实际28次调用、27份可解析输出；其中2份有无效引文，另行计分，不隐藏失败。

## 改善及未解决的案例

**med-116：证据已有，主回答漏答。** 问题同时询问待遇是否改变、普通职工生育待遇的基金来源、灵活就业人员生育医疗费用的基金来源。初稿及普通复查只回答第一项和第三项；第二项虽然在claims和引文中出现，仍未进入主回答。子问复查补入：

> 合并后，参保职工的生育医疗费用和生育津贴所需资金从两项保险合并实施后的职工基本医疗保险基金中支付。

对应E1已包含完整依据，因此这是本次输出中的生成漏答修复，未归因于召回改善。三项要点从2/3到3/3，引用均有效。

**自检记录不能当作真值。** 子问复查9份输出中，只有6份coverage记录符合连续题干短语及E编号约束；med-029改写短语，med-043、med-116使用省略号。med-116又把实际补答项标为covered而非repaired。最终答案虽然改善，但检查轨迹仍不可靠，尚不适合作为自动补检索路由的唯一触发条件。按预先协议，轨迹格式另计，不作为答案评分门槛。

**med-026：来源日期上下文与拒答仍未解决。** 三种回答都摘出了“医疗救助基金全额资助”，却拒绝确认其是否属于题干的2023年通知。当前E4确实只显示2024年缴费标准及资助规定，未给出该来源自身发布日期；不能据此断言只是模型不愿作答。普通复查修复了一条带省略号的引文，子问复查未修复。

本轮沿用实验前冻结的10题rubric及此前parts实验评分，要求直接给出本题的负担结论，因此该题未通过；没有套用后来99题v2中“事实已摘出但年份不确定也可计内容点”的口径。这两种定义不能跨实验直接比较。如果只统计资助事实是否出现在正文，该题三种条件都出现，子问方案相对普通方案仍只多med-116这一题，结论不依赖这个歧义样本的单边评分。

## 决策、限制与复现

达到事先约定的“子问复查有新增、完整有据无退步”开发扩验条件；**默认CLI与RAGFlow网页均未改为两轮方案**。本次不新增付费扩验。下一阶段应在更多开发侧复合问题上冻结子问要点，再验证收益、回退及成本；最终确认需要新的独立政策组，因为原99题已被查看和分析。

10题是反复使用的开发诊断样本，且这次完整答案差异只有一题，没有重复运行来估计波动。温度0及固定seed不保证服务完全确定，不能声称稳定增益或统计显著。不能把上轮9/10和本轮7/10当退化幅度，也不能将这10题结果与99题测试结果相减。
