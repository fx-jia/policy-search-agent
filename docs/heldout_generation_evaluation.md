# 99题生成与引用评测：初版结果，待人工复核评分口径

2026-09-22。两套事前冻结方案的198次生成已运行完毕，194条有效结构输出已由助手逐条评阅；2次TLS失败及2条引用结构不合规输出保留。**这是生成评测初版，不是已经人工验收的最终问答准确率。** 原因之一是生成前拟定的部分复合要点超出了题干明确追问范围，须先复核评分规则，再判断答案是否完整。

## 本轮做了什么

本轮新增的是生成评测与可追溯记录，没有新增检索算法或修改默认方案。复用此前保存的99题候选与上下文，对比开发阶段确定的Dense＋boundary与事前指定的RAGFlow原生Hybrid＋ranked。两组均用现有qwen3.7-flash、短E引用提示、temperature=0、top_p=1、seed=20260921、max_tokens=1200、JSON输出、关闭thinking；每题每组一次，无重试、无pass@3。

这一对照同时改变了检索与上下文选择，是两套方案的比较，不能把生成差值全部归因于boundary。Hybrid对照复用原生RAGFlow检索，但生成通过同一实验客户端完成，不代表RAGFlow网页聊天的完整默认行为。

调用前冻结[协议](<heldout_generation_protocol_v1.md>)、99题227个评分要点、配置、198个请求及所依赖代码。出站415个唯一片段来自182份标为公开的文档；全量规则检查与76块助手定向阅读后，27块去除联系方式、网页链接或非政策个人案例内容，保留全部选中块、ID和顺序。没有新增入库、Embedding、检索或Rerank。

## 为什么先复核评分标准

原始150题及其证据已经用户审核，但**本轮新拆分的227个答案要点尚未经用户审核**。冻结防止了看到模型答案后随意修改标准，却不能保证最初标准合理。

例如med-065只问付款时限和账户方向，两组都答对，却因要点额外要求“省局归集统一拨付”而未判完整；med-104问拔牙、根管、植骨是否包含，冻结要点还要求额外列出牙周洁治和软组织移植；med-132问家属，冻结要点还包括本人，导致两组初判不同。这些说明58/99与61/99目前衡量的是**严格预设复合要点完整性**，不宜直接叫最终问答准确率。

其余条件遗漏中，也存在确实影响适用性的情况，例如med-109未说明申请证照需具备哪些资质，med-119遗漏另一类可合并限额的对象。不能把所有漏项都一并放宽。

已准备12题优先复核（本地归档：`experiments/results/private/heldout-generation-test99-v1/human_review.md`，未收入本备份），前6题检查评分范围，后6题检查跨政策引用、年份拒答和引用指向；同时保存全部未通过记录（本地归档：`experiments/results/private/heldout-generation-test99-v1/failure_ledger.md`，未收入本备份）。这是定向复核，不是随机抽样或盲审。若调整口径，另存v2、对两组一致重评、保留v1，不重新生成以挑选更好答案。

## 检索指标与回答指标的差距

此前原始片段的严格参考覆盖为Dense 87/99、Hybrid 88/99。已覆盖但未通过本轮严格完整性评分分别有33题、30题，原因包括漏答、拒答、跨政策混用以及评分规则本身偏宽，不能全部称为模型事实错误。

也存在严格参考未完整覆盖但回答完成的样本：Dense有med-077、122、139、148；Hybrid有med-050、124、139。连续长参考的背景缺口或有效替代来源不会必然导致答案错误。例如Dense med-122已经拿到900/300元、个人0/5元和次数不足75/70元的全部关键规则；med-148可引用同一政策正式办法支持解读中的要点。

脱敏另使med-111两组的官网链接变为占位符，因此对原长参考的严格字符串匹配由真变假，但三个答案要点及实际引文均正确。本轮没有为此修改原参考标签；上述87/88仍明确指前一阶段原始片段指标。

## 代表问题与后续方向

- **选入证据后仍漏答**：Hybrid med-107漏掉后续机构审核建档及备案；med-113实际E5已包含映射/替换，模型仍未答出。
- **拒答需要区分原因**：Hybrid med-035可用同源条款和2019落款关联，却否认关联；med-059两组的正文规则齐全但所选内容没有2022日期，谨慎拒答有上下文原因，适用性判分需人工确认。
- **范围混用**：Dense med-134把苏州30万元规则混入徐州2022年问题；med-135将2022年的80%归给2020年。
- **答案正确、引用错位**：Hybrid med-100两处引文都写E2，实际依据在E1；med-130两组金额比例正确，但用了省略号拼接原文。
- **格式门槛**：Hybrid med-051、150均返回了可解析JSON，但把“缺少依据”的claim写成空evidence，违反已有输出契约。没有截断，也没有通过重试补救。

后续先完成评分口径与争议样本复核，再在开发集研究政策标题/地区/年份信息如何随片段一起传入，以及漏答和引用错位如何校验。这些是待验证方向，本轮没有实施，更不能在这99题上调好后继续宣称独立测试成绩。

## 用量与验证

198次请求中196次取得正常提供方响应，报告输入325460、输出60697、合计386157 Token。Dense med-050、060为SSLError，未返回用量；因此386157是已报告用量，不能断言是包括失败请求的精确总消耗。没有额外Judge调用。

成功提供方响应的生成延迟均值为Dense 4.52秒、Hybrid 4.58秒；P95分别6.81秒、7.31秒。这不含实时检索，也不是整个服务的生产时延指标。

26项针对性测试和ruff通过。独立脚本核验198个请求、响应、选择及摘要，重算194条有效输出的540条引用（511条字面有效）；另检查2条不合规结构输出中的3条原始引文，均字面有效，问题在空evidence的另一claim。4个评分输出文件离线重放字节一致。程序复算只能证明记录与汇总一致，不能代替独立人工语义判断。

原execution_summary沿用旧辅助函数的`test_queries=0`字段，在此次指没有检索调用，**不代表没有使用测试题**；本轮明确生成了99题198条件，独立审计已作说明。原始记录及冻结代码不回写修改。
