# 10题成对生成验证协议 v1

本轮验证上一步的上下文补全能否改善最终答案，不再修改选择规则。调用前冻结题号、答案要点、模型、Prompt、输出上限、隐私处理和评分标准。选题来自已观察的开发错误，属于诊断样本，不是随机抽样或最终测试。

## 范围与控制变量

使用Dense的已保存ranked与boundary上下文，10题为med-001、017、018、026、029、030、043、090、116、117。其中017、018、043、117是严格证据覆盖改善题，其余用于简单金额、多文档、人群和挤出风险对照。99题测试集不解析、不检索、不生成。

两组保持原始候选、选择算法、2560 cl100k片段预算、生成模型和Prompt一致。仅对选中的正文统一移除联系信息行、图片和网页链接，不补充原文中未被选中的标题、地区、生效日期或答案。报告处理前后的证据覆盖是否一致。生成完整Prompt会包含任务说明、问题和JSON输出格式，因此它的输入Token不等于片段预算。

使用已经配置的`qwen-flash-2025-07-28`固定版本，temperature=0、top_p=1、seed=20260921、非思考模式、JSON对象输出、max_tokens=1200、非流式。服务端仍可能非完全确定。输出参数依据[阿里云结构化输出文档](https://help.aliyun.com/en/model-studio/qwen-structured-output)及[兼容API文档](https://help.aliyun.com/en/model-studio/qwen-api-via-openai-chat-completions)核对。

最多20次生成请求，不调用Embedding、Rerank、联网搜索或其他Judge模型。完全相同的Prompt在两组中复用一次真实生成的响应，单列复用数量。逐题交替哪个条件先请求，无自动重试；鉴权、额度或配置错误立即停止，连续两次其他错误也停止，保留失败记录。

为避免RAGFlow聊天接口重新检索，独立评测器直接调用本地RAGFlow已配置的供应商兼容接口。密钥只在容器内读取并保留于内存，不保存到Prompt、命令行或结果。未修改在线RAGFlow聊天应用。

## 隐私前置检查

来源79870持续禁止向云端发送，保持历史索引不动。对本轮52个独立待发送片段逐一检查，来源79804的一处联系信息行移除。清理图片/网页外链以免把非正文材料引入请求；不读取远端图片。

每个允许发送的片段都绑定来源ID、原文SHA和处理后SHA；未知片段、内容发生变化、命中禁用来源或仍有疑似个人证件号/手机号，均在加载密钥和发请求前失败。准备结果冻结后，实际发送前再次核对摘要。这是新生成评测器的强制检查，不能据此声称旧检索/入库脚本已获得全局隐私保护，也不是全库隐私审计。

## 答案与引用如何评分

金标仅用于评价，不进入生成Prompt。18个答案要点从已人工通过的原始证据中提取，调用前保存。该要点表由助手编写，尚未单独获得用户审核。

1. **答案要点完整**：要求各题的全部核心子问正确，金额需检查对应人群、单位和最低/最高限定；日期需对应正确动作与政策；拒答或只答一部分不计完全正确。附带错误断言也会导致完整正确为否。先做字段/数值筛查，再逐题语义复核，不把全文Exact Match作为问答准确率。
2. **依据忠实**：回答中的实质性政策断言是否被实际发送的上下文支持。回答恰好等于金标，但缺乏上下文依据，仍不算有依据。
3. **引用字面有效**：被引Chunk确实送入模型，且引文在该Chunk中出现（忽略空白/HTML）。这是自动检查，只代表引文真实存在。
4. **引用语义支持**：按每条claim判断引用是否支持该断言及其年度、地区、人群、金额；跨块允许联合支持。引文存在但不支持断言仍判失败。没有任何引用时，不把空分母算成100%。

输出为简洁回答、事实claim、引用片段ID与原文短句，以及依据是否不足。每项claim需有引用，证据不足应明确表达，不得从模型记忆补值。

本轮由助手按冻结规则逐条复核并给出解释；称“助手复核的初步结果”，不称用户人工评测或独立盲评。保留原始输出、实际上下文和自动检查以供用户追查。没有基于LLM-as-a-Judge的额外API评分。

## 成本与结论边界

保存每次实际调用的模型返回名、请求ID、用量、完成原因、耗时、错误类型和输入摘要。Token以服务方实际返回为准，复用响应不重复累计费用；没有可靠价格则不估算账单。复用结果的耗时不视作第二次请求测量，生成耗时不与历史检索耗时相加冒充端到端延迟。

报告10题的成对变化及每题原因。无收益或退步都保留；不能将10题诊断样本的比例外推为51题开发集、99题测试集或整个医保系统准确率。
