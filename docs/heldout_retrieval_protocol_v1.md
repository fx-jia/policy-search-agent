## 已选定的方法和本轮范围

主方案为Dense前64候选、2560 cl100k参考Token预算、原排名前三种子、按未完结边界补直接邻块、短E编号引用和qwen3.7-flash。该方法由51题开发实验选定，RRF、独立局部Rerank、多子问输出未采用。生成提示与参数保留当前默认配置，不因本轮测试结果更改。

本轮只执行**检索与上下文评测**：99题分别运行Dense和原生RAGFlow Hybrid各一次，共最多198个检索请求流程。Hybrid沿用原API及原参数，vector_similarity_weight=0.3，不启用Rerank、关键词LLM扩展、跨语言、KG、TOC或知识编译。Dense使用已验证的纯ES KNN适配，向量权重1、KNN1024、候选搜索2048、相似度阈值0、返回64。两组都固定相同1000篇/3205块范围，不用问题正例过滤。

通过这两个排名，在本地分别执行ranked和boundary选择，共4个条件、396条上下文记录。两种选择均保持2560参考Token预算；boundary仅补同一物理文档、已在64候选内的直接邻块，不递归、不查询候选外内容。

主要消融：Dense+boundary相对Dense+ranked的完整证据覆盖变化。系统参考：Dense+boundary相对原生Hybrid+ranked；另报告Hybrid+boundary及文档Recall/MRR。此处baseline是RAGFlow原生检索能力，不能将它描述成整个RAGFlow网页问答系统的端到端对照。
