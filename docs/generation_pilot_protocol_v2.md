# 生成诊断的执行修订 v2

沿用[首次协议](<generation_pilot_protocol.md>)的10题、18个答案要点、两组上下文、Prompt、参数、隐私处理和评价标准。首次执行得到一次TLS连接错误与一次403权限拒绝，0个有效回答；20条计划记录、2次尝试及当时源代码保留在`generation-pilot-dev10-v1`。其汇总用量0仅代表未获得用量字段，不能证明实际账单为0。

只读查询已配置Key的云端模型目录，发现未列出`qwen-flash-2025-07-28`，但列出已在本地配置的`qwen3.6-flash-2026-04-16`。目录可见不等于保证推理权限；本轮改用后者固定版本，实际调用验证权限。没有根据回答效果换模型，因为第一轮没有有效回答。

连接诊断中httpx发生TLS EOF，Requests曾完成401无密钥响应及200带密钥目录查询。因此改用保持TLS验证的Requests Session，复用连接，无自动重试。其余服务和模型参数不变，不修改RAGFlow核心配置。记录供应商错误码但不记录潜在敏感的原始错误信息。

本轮最多18次实际生成，配合初次的2次尝试累计不超过20次。仍有20个条件结果，相同Prompt复用响应；有错误就按首次协议停止。新模型的两组输出只能在v2内比较，v1失败不混入模型准确率对照，单独报告可用性问题。没有供应商用量的请求记未知，不能将缺失字段当0成本。

再次冻结发送材料与代码摘要后执行，最初的隐私审批核验仍适用相同目的地和相同正文。实际输出目录为`experiments/results/private/generation-pilot-dev10-v2/`。
