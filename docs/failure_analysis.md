当前完整系统诊断见新模型原生端到端基线（本地归档：`docs/native_baseline_results.md`，未收入本备份）：150 题已真实生成，5 题实际 Prompt 缺必答依据，另有金额/条件混淆、漏项和引用错位。全文保留了评分粒度争议与归因边界；以下记录对应各自历史阶段，不代表当前仍未运行生成。

最新测试诊断：[99题正式检索结果](<heldout_retrieval_evaluation.md>)保留396条上下文中的全部47条不完整记录，涉及24题、49个参考段。所有缺失原标参考均已进入对应64候选，直接缺口位于预算内选择。Dense补全新增7题完整覆盖、退步3题：med-049和148挤出含核心条款的原标块，med-139只丢参考背景、主问数值仍在；4道新增题主要补回章节标题。不能将严格覆盖变化直接换成问答得失。完整机器诊断见failure_cases.jsonl（本地归档：`experiments/results/private/heldout-retrieval-test99-v1/failure_cases.jsonl`，未收入本备份），全24题与10道Dense变化逐题解释见报告。未改测试标签、未运行生成。

最新生成错误：[多子问回归](<policy_qa.md>)在相同上下文下，med-116补回主回答漏项但出现引文省略拼接；med-029把不含长护险的420元错误理解并答400元；med-026混淆发布年和缴费年度；med-001额外说明未配齐引用。全部20份原始输出和评分理由已保存，新格式未采用。一次实时串联中同样短编号Prompt又能答全med-116，作为输出波动记录，未冒充修复成功。

最新错误分析：[独立局部Rerank](<independent_rerank_evaluation.md>)在51题全部请求成功时仍出现4道boundary严格覆盖退步：med-026、029、115、116。已逐题检查，包含具体条款被封面/总则压后、边界扩展占用预算，以及med-029仍可从替代证据推算答案。未将严格指标退步直接记为生成错误；完整27条不完整上下文见分析记录（本地归档：`experiments/results/private/dense-partial-rerank-dev51-v1/analysis.json`，未收入本备份）。

本报告针对2026-09-21的1,000篇语料、51题三组基线，依据保存的真实排名、Top5 Chunk、原始参考证据和脱敏日志。**没有生成回答**，不能判定 Generation Failure、回答幻觉或引用错误。原始检查由助手完成；其中首批候选的人工复核状态以上方补标进度为准。

## 筛查数量与口径

| 现象 | Dense | Hybrid | Hybrid + Rerank |
| --- | ---: | ---: | ---: |
| 请求错误 / 51 | 0 | 0 | 11（21.57%） |
| 成功请求中文档 Recall@5 不足1 / 成功数 | 0/51 | 2/51（3.92%） | 1/40（2.50%） |
| 成功请求中参考证据未逐段完整字面匹配 / 成功数 | 8/51 | 8/51 | 6/40 |

后两行会重叠，不能相加。22条成功请求的字面未匹配涉及10道不同题；加上11条服务错误，共33条记录、19道不同题。下面逐一分析全部10道题，错误请求另表说明，未用重复错误凑出不同算法问题。

已确认的**核心答案在前5块缺失**有7条方法—问题记录：Dense 2条、Hybrid 4条、Rerank 1条，分别占各自成功请求的3.92%、7.84%、2.50%。这些是本轮筛查后核验的具体缺口，不是穷尽语义标注或回答错误率。其余字面未匹配包含背景缺失、跨块可组合、核心答案已在、替代证据待补标，不能全部算作检索失败。

| 题号 | 观察 | 归因与处理 |
| --- | --- | --- |
| med-004 | 三组均找到65%及2019年政策标题，但缺少单独标注的实施时间、适用地区背景段 | 辅助证据覆盖不全；不能直接判定答案错误 |
| med-017 | 三组均找到1350元及政策标题，同样缺少背景段 | 同上；需区分直接答案与背景约束 |
| med-018 | Dense找到2019年政策首块，真正的实施日期和地区块排第34；Hybrid在第1块、Rerank在第2块找到答案 | 答案块排序缺口；文档Recall掩盖问题 |
| med-027 | Dense已标来源的答案块在第6，但第1块来源79343的政策问答已经给出98天与计发基数，原通知第2块提供2026年条件 | 替代正例待补标；不能只因来源不同判错。Rerank此题为服务错误 |
| med-008 | Hybrid中2024年缴费原文排第8个文档，前5为长护险资金/机构材料，缺少420+20=440的完整依据；其他两组命中 | 返回窗口内已有证据，但最终前5排序偏低 |
| med-029 | Hybrid与Rerank中2024年来源第3、2022年来源第6，缺少比较的一侧；Dense两侧齐全 | 多文档排序与覆盖缺口，不能用Hit Rate代替Recall |
| med-043 | 财政补助670元与个人缴费380元被分在两块；Dense/Hybrid只选到前一块。Rerank前5包括两块 | 分块边界与排序共同作用。Rerank可组合回答，单块整段字面匹配仍为false |
| med-045 | Dense/Hybrid已找到2024年1月31日截止日期，参考长段落的开头在另一块 | 核心答案已在，整段匹配过严；Rerank此题为服务错误 |
| med-090 | 学校12月20日截止已找到；非就业居民12月25日及次年元旦待遇所在块在Dense第4、Hybrid第6、Rerank第5 | Hybrid缺少第二个子问的答案；另两组只缺额外学生待遇背景段 |

## Rerank连接故障

失败题号：med-006、007、010、026、027、032、041、042、045、086、088。11条请求都保留 `ragflow_application_error`，空检索结果按零分计入主指标。对应运行时间窗的日志有11条带Rerank调用栈的TLS EOF异常；没有发现额度耗尽或429模式，日志诊断只保存类别、时间与计数。

这是工程可靠性问题，不应归入语义 Retrieval Failure 或 Ranking Failure。成功40题与其他方法配对后，Rerank来源Recall@5为98.75%、Hybrid为96.25%，详见对照报告（本地归档：`docs/baseline_comparison.md`，未收入本备份）。成功子集不能替代主结果，也没有证明在失败的11题上重排效果如何。本轮没有更换实现后重跑，也没有静默退回Hybrid掩盖错误。

## 对七类失败的判断边界

| 类别 | 当前证据支持的结论 |
| --- | --- |
| Retrieval Failure | 原生API没有完整初始候选轨迹，不能据最终结果给出可靠发生率；成功请求的返回64块覆盖所有已知正例文档，不等于覆盖全部答案块 |
| Ranking Failure | 上表7条核心证据缺口在返回窗口内有相应证据块，却未进入前5；其中3条是文档来源排序、4条是同文档答案块排序 |
| Chunking Failure | med-043在金额规则中间断块，影响Dense/Hybrid两个请求；与排序缺口重叠，不独立相加 |
| Context Failure | 尚未组装生成Prompt或执行截断，不能评估生成阶段上下文处理错误；当前只检查预定前5块 |
| Generation Failure | Not Run |
| Policy Ambiguity | 有跨年度、地区和缴费子项目干扰，但这些已审核题仍有明确指定条件；不能把检索到旧政策直接算成问题本身歧义 |
| Unsupported Question | 当前题集全部有答案，未构建不可答题，也未评估系统是否错误地确定回答 |

完整参考段可能跨块，原生API也未暴露所有内部阶段，所以各类不能强行互斥，更不能给没有测量的类别填写0%。

## 后续实验进展

多方法结果池最初有331个待判定配对；现已完成两批20对审核，新增2条充分支持正例，保留6条部分支持和12条不支持判断。标签v2已用保存排名重算三组指标。剩余311对维持未审核，暂停继续发批次，不将未审核自动标为错误。

算法侧优先考虑**有限的文档内证据补全**：从已召回来源的现有块中补足相邻规则或另一子问的依据，并在固定总Token预算下重新选择上下文。它直接对应med-018、043、090，不需要重新嵌入语料。但不能根据金标ID补块，不能把扩大上下文预算包装成算法收益，也可能引入更多旧版本或无关段落。

固定候选、开发标签、2560 Token预算和三种规则的离线实验已完成：Dense严格参考覆盖从44/51提高到48/51，其中med-018和043补回核心答案，另外两题主要补全背景或长参考段。直接补块有挤走其他答案的退步案例，边界约束在该开发轮避免了这些损失。见优化报告（本地归档：`docs/optimization.md`，未收入本备份）与消融分析（本地归档：`docs/ablation_study.md`，未收入本备份）。后续统一问答入口已接通，99题检索结果见页首；生成测试仍待完成。原生Rerank的11次历史错误没有被后续成功的独立重排实验覆盖。
