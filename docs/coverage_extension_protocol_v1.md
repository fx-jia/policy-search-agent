# 子问覆盖复查扩验：其余41道开发题

2026-09-23，用户授权继续验证收益。实验前冻结，不用原99题调试，不重复前10题，不合并前10题当作同期结果。

## 问题和控制

将开发51题中前轮10题排除，其余41题全部纳入，不按已知生成错误挑题。共6个政策组，与早期开发题有同政策来源，不能当成独立测试集。助手在模型运行前按用户已审核题干及原文写出74个必答要点，不额外要求题干未问的事实。多要点题20道、单要点题21道，预先按rubric至少2项分组；分组是回答要求数量，不声称所有多要点题都是独立多跳推理题。

保留原提示模板、参数、Dense64候选及boundary2560的已保存上下文。115个实际选中片段，本地复用55个既有审查及新读60个；只做既有联系信息/链接脱敏，不按答案改写政策正文。使用qwen3.7-flash，temperature=0、top_p=1、seed=20260921、max_tokens=1200、JSON输出、关闭thinking。

每题生成一个新初稿；普通复查与子问复查使用同一初稿、同一问题及同一证据，互不读取对方结果。两种复查均是两次调用的逻辑方案。拆问、提示模板、输出schema均不因前轮检查轨迹错误而调整：本轮验证原方案能否推广，不混入额外改动。rubric不会进入模型输入。

## 执行边界

按既定题序分5批（10/10/10/10/1题），复用原执行器，每批最多30次、每个worker会话最多15次，整体最多123次，无重试、pass@k、Embedding、检索或Rerank。每题交替复查先后；由于前4批都是偶数题，批界不改变交替顺序。

每批执行器遇鉴权/额度/配置/协议错误，或批内两个连续提供商错误，即停止该批；之后所有批也停止并补记未运行记录。传输错误计数在批界重置；此规则提前记录。单题初稿失败则跳过依赖分支，其他题继续。所有失败、截断与跳过都保留41题分母；不因结果不理想续跑挑样本。

## 评分与决策

复用既有score_record及引用字面检查，助手逐题检查主回答的必答要点、额外错误、忠实性、claims覆盖及引用语义支持。主指标为完整有据题数；同时报告答案完整题数、74个要点覆盖、多/单要点子组、逐题新增和退步、Token及耗时。coverage自报及格式单独审计，不作为判分真值或答案通过门槛。

内容评分接受“已明确回答事实，同时注明来源日期不确定”，但明确拒绝给出本题结论不算回答；年份确认、证据忠实性与引用另评。只按题干范围，不能从参考证据附带内容增加要求。评分口径在本次41题内部统一；不与前10题或99题绝对分数直接相减。

预先决策：子问方案相对普通复查完整有据净增必须为正，且相对初稿也必须净增为正，才值得继续优化。出现任何实质性无依据事实新增须列出；即便净增，也不自动切换生产默认。若没有净增或收益主要是一般复查带来，则报告该方案尚无额外收益，停止扩展这一版本。不在原99题上再试到更好为止。
