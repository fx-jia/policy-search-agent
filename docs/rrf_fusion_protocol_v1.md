# RRF 与分数融合对照：预先冻结的实验协议

目标：检验在相同的正文 BM25 与 Dense 候选输入下，按名次融合能否改善前排证据与固定预算内的完整证据覆盖。允许无提升或退步；不根据结果修改本轮参数。

## 数据及边界

- 只使用已冻结的 51 题开发集、1000 文档 / 3205 原有 Chunk；99 题测试集只校验文件哈希，不读取题目。
- Dense 使用已保存的每题前 64 个候选及 cosine 分数，不重新调用 Embedding。
- BM25 使用本地 Elasticsearch 的 `content_ltks` 字段，默认 BM25（k1=1.2、b=0.75），RAGFlow 粗粒度分词，OR 匹配至少一个词；采用 dfs_query_then_fetch 合并分片词频统计。不扩词、不改写问题、不调用模型。索引标题字段采用自定义 similarity，故不纳入这一路标准 BM25。
- 所有问题固定相同的 1000 文档、2 个知识库过滤器，排除 available_int < 1。绝不按金标文档过滤。返回前 64 个 Chunk，分数降序、id 升序打破同分。保持快照索引 UUID、主分片序列号及文档数不变。
- BM25 词频统计仍来自共享的原索引，包含固定范围之外的文档；过滤器限制返回范围，不将统计缩小为 1000 文档。该设定对两种融合相同。
- BM25 路径是本实验明确实现的正文词项检索，并非原生 RAGFlow 的全文查询构造器。原生 Hybrid 的历史结果只作独立系统参考。

## 单变量对照

对每题，先保存并冻结两路候选，然后形成并集（至多 128 块）。两种方法均只使用这两份输入：

1. `weighted`：每路在返回的前 64 块内做 min-max 归一化；缺席贡献为 0；若该路所有分数相等，则在场项归一化为 1。最终分数 = 0.5 × BM25 归一化分数 + 0.5 × Dense 归一化分数。
2. `rrf`：分数 = Σ 1 / (60 + rank)，名次从 1 开始，缺席贡献为 0，两路等权；60 沿用原论文常用设定。

两种方法均按最终分数降序、Chunk ID 升序截取前 64 块。没有网格搜索、重排模型或基于标签的 tie-break。Min-max 的尾项贡献为 0、缺席分数缺失、RRF 会偏好两路共现项，均作为算法设定和局限保留；没有为并集中的缺席项重新计算另一路分数。

控制组：BM25 单路、Dense 单路；系统参考：已保存的原生 Hybrid。Dense 和系统参考保持历史顺序，BM25 的同分规则按上述规定。两个融合方法的严格对照不涉及原生 Hybrid，也不声称优于所有可能的加权方法。

## 上下文和指标

- 主对照：各方法使用已有 `ranked` 规则，按检索顺序装入整块，跳过超预算块；预算 2560 cl100k 参考 Token，沿用快照中的正文、来源 / Chunk 头和分隔符计数。
- 次对照：同样分别使用此前冻结的 `boundary` 规则，seed_top_k=3。只在同一上下文规则内比较融合方法。邻块必须位于各自输出的前 64 候选内，不从全库扩展。
- 主要指标：所有原始参考片段的完整覆盖 / 51。允许同文档连续块拼接；它是严格文本证据代理指标，不是答案正确率。
- 次要指标：允许已人工审核替代证据的覆盖、参考片段覆盖率、证据全部出现时所需的最短候选前缀名次及其倒数均值（缺失计 0）、文档 Recall@5 / MRR@10、平均上下文 Token。
- 同时报告两路并集的无预算参考证据上限和融合后前 64 候选上限，以区分候选缺失、排序截断与上下文预算问题。
- 已审核不支持、部分支持及未审核来源的 Token 分开计数；未审核不等于不相关，不将不完整 qrels 推导成精确 Precision。
- 全部 51 题计入分母。服务错误必须保留；初始化或索引不一致时停止，不降级到另一检索算法。以 6 个政策组做配对 bootstrap（seed=20260922，2000 次），区间仅供探索，不能替代独立测试。

## 冻结和复现

在调用 BM25 前保存配置、协议、代码及依赖数据 SHA256；候选保存后、加载金标评分前保存候选冻结清单。检索与融合阶段只允许问题、候选 ID、分数和 Chunk 元数据进入选择逻辑。先保存各方法排序与上下文，再加载答案和 qrels。保留每路贡献、逐题结果、所有新增覆盖与退步；代码和配置不得在查看首次结果后无说明地改写。

不增加文档、不改线上 RAGFlow，不调用生成模型，也不估计问答提升或生产端到端延迟。BM25 的本地检索时间与融合纯计算时间分开记录，历史 Dense 延迟不可与本轮直接作耗时消融。

RRF 是既有方法，本项目贡献是实现、受控评测及决策依据，不是提出 RRF：[Cormack 等，SIGIR 2009](https://plg.uwaterloo.ca/~gvcormac/cormacksigir09-rrf.pdf)。
