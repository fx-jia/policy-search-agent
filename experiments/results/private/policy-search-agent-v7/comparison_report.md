## 本次具体改了什么

1. **选择证据片段编号，代码恢复原文。** 控制器接收带ID的可见原文，只返回`evidence_ids`。代码绑定Chunk、原文位置和文档身份。换行保持原样，禁止用模型抄写的quote替换原文，从接口上避免013的换行差异和057的条号拼接。
2. **固定行动层级并区分错误类型。** 全局action置于根层，needs只允许text/status/evidence_ids；非法模型决策、来源校验、传输与预算错误分别处理。supported表示“足以回答”，包括有依据回答“不能”。本次052判为sufficient，未再将否定答案误标为证据不足。
3. **受限降级。** 模型决策非法且时间允许时，用初检的完整原生结果进行一次最终回答；仍受原预算及未知用量保护，保留controller_error/fallback_used。来源错误、传输异常与超时不因此放行。30道强制错误回放中，最终请求与固定原生RAG逐字段一致，零外部调用。真实批次降级触发0次，不能声称它已贡献内容分数。
4. **先保留已选证据，再补充周边文字。** 回归测试发现，先扩展第一段限定条件可能挤出第二段已选证据；现在先预留全部已选原文，再加入周边条件。超过8个已选来源会显式拒绝，不能静默丢弃后仍声称充分。
5. **补齐审计。** 控制器错误与降级在生成前落日志，宿主超时保留已知状态；事件不完整单列。另修正离线报告：已准备但因预算未发送的请求，不计入“实际最终上下文覆盖”。这项报告修正没有改变正在执行的策略。

模型保持deepseek-v4-flash-0731非思考；Embedding保持qwen3.7-text-embedding；语料仍为1000篇/3205块；初检Hybrid参数不变。没有改变原生RAG/Low文件、重新入库、运行High或使用95道测试题。
