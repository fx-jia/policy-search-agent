# 新增60道开发题：调用前固定协议

- 沿用上一轮输出前预选的60题，Easy/Medium/Hard各20，19个政策组；其中38题与原30题共享政策组，不称未见政策泛化。无原30题重叠；95测试题不执行。
- Native RAG、Native Low、v7各60题；同deepseek-v4-flash-0731非思考、原qwen3.7-text-embedding、1000篇/3205块、现有统一出站脱敏。v7推理模块逐字沿用确认批次，不因中间结果改策略。
- 每方案串行1；方案依次RAG、v7、Low。前一并发2批遇到Elasticsearch OOM，整批作为基础设施中断记录保留，不纳入内容收益。服务恢复后从固定60题重新运行；模型、题目和推理源码不变。服务波动及资源限制仍列为耗时比较限制。
- 每题上限保持各方案既有配置：RAG 60秒/2次生成/4次查询向量；Low 90秒/14次生成/24次查询向量；v7 60秒/4次生成/3次查询向量。原生Low的查询上限中止单列，不伪装成模型内容错误。批次预算为每题上限之和，不扣旧额度。
- Native RAG/Low保持原工作进程和冻结模块；只更新宿主调度源码校验值、题目清单、批次上限及独立账本位置。v7执行冻结源码。原生连接保护沿用原协议，v7沿用获准有限重连；已发送或不明状态不重试。
- 不覆盖失败、不择优重跑；记录错误、未知用量与未完成题。可确认未发送的连接失败之后仅续跑未尝试题。未知用量先检查隔离进程及独立账本，不把未知记为0。
- 核心指标：题干必答点通过/60、逐点覆盖、新增通过/退步、按难度与政策组、证据可支持性和引用问题。额外错误/无依据解释单列，不能把核心通过称为全文无错。
- 语义评分为助手逐题阅读，原文含义等价即可，不要求照抄参考答案；不扩大题干范围。争议样本进入人工复核，给出已确认下限和待复核区间。新而可能正确的依据不直接计引用错误，补标适用于全部方案。
- 控制器只接收题干与真实可见证据；参考答案、难度与评分只在离线评阅读取，不反馈给本批算法。
- 记录生成输入/输出Token、查询Embedding成功调用、可得物理请求及Token、均值/P95耗时、控制器错误、补检/邻块、缓存命中和停止原因。历史原生物理向量遥测不可得时为null，不能写0或与v7混算缓存收益。
- 若本批出现补检，先根据逐题轨迹分析；消融另建批次，不能把途中修改的策略结果拼接。最后报告负收益、失败及评分争议，不只展示改进题。
